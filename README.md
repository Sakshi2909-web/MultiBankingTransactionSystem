## 📖 Overview

The **Multi Banking Transaction System** is a banking application developed using **Java, JDBC, and MySQL**. It provides essential banking services such as account management, deposits, withdrawals, fund transfers, and transaction tracking through a user-friendly interface.

---

## ✨ Features

✅ User Registration & Login  
✅ Create New Bank Account  
✅ Deposit Money  
✅ Withdraw Money  
✅ Check Account Balance  
✅ Fund Transfer Between Accounts  
✅ View Transaction History  
✅ Secure Data Storage using MySQL  
✅ JDBC Database Connectivity
